# Software and data

Code is on [GitHub](https://github.com/kbryson). Selected repositories:

<div class="repo"><h3><a href="https://github.com/kbryson/gGAN">gGAN</a></h3><p>Generative adversarial networks for gene-expression data, accompanying <em>Adversarial generation of gene expression data</em> (Bioinformatics, 2022). Jupyter notebooks.</p></div>

<div class="repo"><h3><a href="https://github.com/kbryson/MCbiclust">MCbiclust</a></h3><p>Massive correlating biclusters for discovering large co-regulated gene sets in transcriptomic data collections. R package; also on <a href="https://bioconductor.org/packages/MCbiclust/">Bioconductor</a>.</p></div>

<div class="repo"><h3><a href="https://github.com/kbryson/MCbiclustWebApp">MCbiclustWebApp</a></h3><p>Web front-end for running and exploring MCbiclust analyses. Python.</p></div>

<div class="repo"><h3><a href="https://github.com/kbryson/nuclear_image_analysis">nuclear_image_analysis</a></h3><p>Deep-learning notebooks for nuclear detection and analysis in histopathology images.</p></div>

<div class="repo"><h3><a href="https://github.com/kbryson/liposarcoma">liposarcoma</a></h3><p>Analysis code for a liposarcoma study combining imaging and molecular data. Python.</p></div>

## Earlier tools

- [PSIPRED Workbench](http://bioinf.cs.ucl.ac.uk/psipred/) — protein secondary structure, disorder, domain and fold prediction (UCL Bioinformatics Group)
- [ViMMS](https://github.com/glasgowcompbio/vimms) — virtual metabolomics mass spectrometer (Glasgow), including TopNEXt
